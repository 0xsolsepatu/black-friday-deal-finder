Bargain Beacon — 50 real Black Friday deals, each read at its store on 27 Nov 2026 and given an honest verdict: new low, strong deal, or routine cut.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — search, filter by category, store, discount and verdict, sort, open any deal for its source and check time, and compare the same product across stores.
